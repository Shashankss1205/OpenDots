Sources collect information. Subscriptions route it to an agent. Matching events are assessed against the goal when model relevance is enabled.
Connect a source or create your own event
An event is a JSON object with a type, source, and payload. You choose names such as input.build_failed; there is no fixed list of custom event types.
Use the form below for a local message, or send the same JSON to POST /api/events with Content-Type: application/json and X-OpenDots-Request: dashboard.
JSONL: add a jsonl source with an inbox path, then append one JSON event per line. GitHub polling: add a github_poll source with a repository. Heartbeats: add a schedule. Each needs a matching target subscription. Restart after config edits.
GitHub webhooks need a signing secret and a receiver that forwards to this local runtime. Kafka, Redis, Slack, and email need an external bridge or a trusted source plugin.
